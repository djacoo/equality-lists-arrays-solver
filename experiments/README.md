# Experiments

This directory contains the experimental evaluation framework for the Equality, Lists, and Arrays Solver (Phase 4.2 of the project plan).

## Overview

The experiment framework systematically evaluates the solver's performance across all test cases, measuring:

- **Correctness**: SAT/UNSAT results compared to expected outcomes
- **Performance**: Wall-clock runtime and solver-reported time
- **Problem characteristics**: Number of literals, function applications
- **Theory coverage**: Results by theory (T_E, T_cons, T_A, combined, SMT-LIB)

## Files

### Scripts

- **`run_experiments.py`** - Main experiment runner
  - Runs all test cases from `tests/input/`
  - Collects timing and correctness data
  - Outputs results to `results.csv`

- **`analyze_results.py`** - Results analysis tool
  - Reads `results.csv`
  - Generates summary statistics
  - Identifies failed tests and errors

### Data Files

- **`results.csv`** - Experiment results (generated by `run_experiments.py`)
  - Columns: test_id, category, filename, expected, result, correct, wall_time_ms, solver_time_ms, literals, functions, success, error

## Running Experiments

### Prerequisites

1. Build the solver JAR:
   ```bash
   mvn clean package
   ```

2. Ensure Python 3 is installed:
   ```bash
   python3 --version
   ```

### Run All Experiments

From the project root or experiments directory:

```bash
python3 experiments/run_experiments.py
```

Or make it executable and run directly:

```bash
chmod +x experiments/run_experiments.py
./experiments/run_experiments.py
```

This will:
- Find all test files in `tests/input/`
- Run the solver on each test
- Measure performance
- Save results to `experiments/results.csv`

Expected runtime: ~1-5 minutes for all tests

### Analyze Results

After running experiments:

```bash
python3 experiments/analyze_results.py
```

Or:

```bash
chmod +x experiments/analyze_results.py
./experiments/analyze_results.py
```

This will display:
- Overall statistics (total tests, correctness, SAT/UNSAT distribution)
- Timing statistics (average, min, max runtime)
- Results by category
- Problem size statistics
- List of failed tests (if any)
- List of errors/timeouts (if any)

## Experiment Design

### Test Categories

1. **te** - Theory of Equality (T_E)
   - Pure congruence closure tests
   - Examples from Bradley & Manna Section 9.3

2. **tcons** - Theory of Lists (T_cons)
   - List operations: cons, car, cdr
   - Examples from Bradley & Manna Section 9.4

3. **tarray** - Theory of Arrays (T_A)
   - Array operations: select, store
   - Store decomposition tests
   - Examples from Bradley & Manna Section 9.5

4. **combined** - Mixed Theories
   - Tests combining T_E + T_cons, T_E + T_A, T_cons + T_A
   - Tests with all three theories

5. **smtlib** - SMT-LIB Format
   - QF_UF logic tests
   - Standard benchmark format

### Metrics Collected

For each test case:

- **Test Identification**
  - Test ID (sequential number)
  - Category (theory)
  - Filename

- **Correctness**
  - Expected result (from filename/header)
  - Actual result (SAT/UNSAT)
  - Correctness flag (match expected)

- **Performance**
  - Wall-clock runtime (Python measurement)
  - Solver-reported time (internal timing)

- **Problem Characteristics**
  - Number of literals (equalities/disequalities)
  - Number of function applications
  - (Future: DAG size, equivalence class count)

- **Execution**
  - Success flag (clean exit)
  - Error message (if any)

## Results Format

The `results.csv` file contains the following columns:

| Column | Description |
|--------|-------------|
| `test_id` | Sequential test number |
| `category` | Test category (te, tcons, tarray, combined, smtlib) |
| `filename` | Test file name |
| `expected` | Expected result (SAT/UNSAT/UNKNOWN) |
| `result` | Actual result from solver |
| `correct` | True if result matches expected |
| `wall_time_ms` | Wall-clock runtime in milliseconds |
| `solver_time_ms` | Solver's internal reported time |
| `literals` | Number of literals in the problem |
| `functions` | Number of function applications |
| `success` | True if solver exited cleanly |
| `error` | Error message if any |
